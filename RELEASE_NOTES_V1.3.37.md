# BMT Voice Studio v1.3.37 — Update-channel release

## Why this build

Portable Windows package for **Help → Check for Updates**. Existing 1.3.36 installs should see this as newer and download `BMTVoiceStudio-1.3.37-Windows-x64-Portable.zip` from GitHub Latest.

## Included

- Packaging includes the app icon, default video clips, meditation stills, and background music in both the wheel data and the generic PyInstaller spec.
- Edge health status shows the real provider message when the service is unavailable.
- Same Daily Audio + Video Maker workflow as 1.3.36.

## Install / update

1. In the app: **Help → Check for Updates → Download update → Install update and restart**.
2. Or extract the portable zip and replace the previous `BMTVoiceStudio` folder.
