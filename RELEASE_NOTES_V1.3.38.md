# BMT Voice Studio v1.3.38 — Update-channel release

## GitHub

- Source: https://github.com/oneskareb-beep/BMTVoiceStudio-Source
- This zip: https://github.com/oneskareb-beep/BMTVoiceStudio/releases/tag/v1.3.38
- Latest: https://github.com/oneskareb-beep/BMTVoiceStudio/releases/latest

## Why this build

Portable Windows package for **Help → Check for Updates**. Existing 1.3.37 installs should see this as newer and download `BMTVoiceStudio-1.3.38-Windows-x64-Portable.zip` from GitHub Latest.

## Included

- One tool, two ministries: choose **BMT** or **HHR (Hope & Healing Africa — Ruhuka Umutima)** in the header before generating.
- BMT workflow, languages, and branding stay the same.
- HHR uses Swahili voice, a required Kinyarwanda transcript (large on-screen text), English captions (medium), HHR logo, and the green Ruhuka Umutima look.

## Install / update

1. In the app: **Help → Check for Updates → Download update → Install update and restart**.
2. Or extract the portable zip and replace the previous `BMTVoiceStudio` folder.
