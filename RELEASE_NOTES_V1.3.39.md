## Why this build

1. **Video thumbnails / intro cards** now follow the Believers Manna Today flyer: BBNet logo, BELIEVERS / MANNA TODAY, Daily Devotional banner, author box, wooden signposts. Quote, theme, and date change per day. Background photo stays in that look.
2. **Swahili audio** now uses East African Kenya neural voices (`sw-KE-RafikiNeural` / `sw-KE-ZuriNeural`) instead of Tanzania. Edge has no West African or Congo Swahili voices. Existing Tanzania settings upgrade automatically.

## Install / update

1. In the app: **Help → Check for Updates → Download update → Install update and restart**.
2. Or extract the portable zip and replace the previous `BMTVoiceStudio` folder.
